Como funciona a edição de um cadastro

Objetivo Segurança Busca Atualização Fluxo
01 — OBJETIVO

O que o arquivo faz?

O arquivo alterar_estudante.php permite editar os dados de um estudante já cadastrado no sistema.

Ele busca os dados atuais, mostra as informações no formulário e salva as alterações no banco de dados.
02 — SEGURANÇA

Verificação do usuário

Primeiro, o sistema verifica se o usuário está conectado. 

session_start();

if (!isset($_SESSION['usuario_id'])) {
    header("Location: index.php");
    exit;
}

Se o usuário não estiver logado, ele será enviado para a página inicial.

03 — BUSCA DOS DADOS

Encontrando o estudante

O sistema recebe o ID do estudante pela URL e procura esse registro no banco. 

$stmt = $pdo->prepare(
    "SELECT * FROM cadastro_estudantes
     WHERE auto_num = :id"
);

$stmt->bindValue(':id', $id_estudante);
$stmt->execute();

$aluno = $stmt->fetch();

Os dados encontrados são armazenados na variável $aluno.

04 — ATUALIZAÇÃO

Salvando as alterações

Quando o formulário é enviado, os dados são recebidos pelo método POST. 

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nome = trim($_POST['nome']);
    $turma = trim($_POST['turma']);
}

Depois, o comando UPDATE altera os dados do estudante no banco. 

UPDATE cadastro_estudantes
SET nome = :nome,
    turma = :turma
WHERE auto_num = :id
05 — FUNCIONAMENTO

Fluxo do sistema

1. Login
2. Recebe o ID
3. Busca os dados
4. Edita o formulário
5. Atualiza o banco

Após salvar, o sistema redireciona o usuário para a página de consulta.
